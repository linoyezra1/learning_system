# תיקיית Public - קבצים להורדה

כדי לאפשר הורדת החוברת, יש להעתיק את הקובץ (שם הקובץ לא לשנות):

**חוברת לימוד עזרה ראשונה.pdf**

לאחת מהמיקומים הבאים:

1. **תיקייה זו** – `public/חוברת לימוד עזרה ראשונה.pdf` (מומלץ)
2. **שורש הפרויקט** – `חוברת לימוד עזרה ראשונה.pdf`

לאחר העתקה, החוברת תהיה זמינה להורדה דרך עמוד "חומרי לימוד להורדה והדפסה" וכפתור "הורד".
